# Mini Sama Codex Pet

Installed with:

```powershell
npx --yes codex-pets add mini-sama
```

Local Codex install path:

```text
C:\Users\Matteo\.codex\pets\mini-sama
```

This repository copy keeps the pet package versioned:

- `pet.json`
- `spritesheet.webp`

The `codex-pets` CLI currently exposes install commands (`add` and `add-collection`).
To use the pet in Codex, open the Codex pet selector/settings and choose `Mini Sama`
after installing it.
